# 📦 Inventario Básico de Productos con Python

> Proyecto práctico realizado durante el curso **Iniciación a la Programación con Python**.

## 📌 Descripción

Programa interactivo de consola desarrollado en **Python** para gestionar un inventario básico de productos.

El usuario puede agregar productos, indicar sus cantidades y consultar los productos registrados en el inventario.

El programa también controla que las cantidades ingresadas sean válidas y evita registrar el mismo producto como un elemento separado, acumulando las unidades cuando el producto ya existe.

## ⚙️ Funcionalidades

* ➕ Agregar productos al inventario.
* 🔢 Registrar la cantidad de unidades.
* 🔎 Detectar si un producto ya está registrado.
* 📦 Actualizar el stock de productos existentes.
* 📋 Mostrar todos los productos en una tabla.
* ⚠️ Validar datos ingresados por el usuario.
* 🚪 Salir del programa mediante un menú interactivo.

## 💻 Ejemplo

```text
=============================================
       MENÚ DE GESTIÓN DE PRODUCTOS
=============================================
1. Agregar producto al inventario
2. Mostrar productos registrados
3. Salir
=============================================
Ingresa una opción (1, 2 o 3):
```

Al consultar el inventario:

```text
=============================================
              INVENTARIO ACTUAL
=============================================
Producto                         Cantidad
---------------------------------------------
Yerba                                   10
Arroz                                   15
Galletitas                               8
=============================================
Total de productos registrados: 3
```
